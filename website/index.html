Questions

Is it really free? What's the catch?

There isn't one. No trial, no watermarks, no “pro” version, no ads and no data collection. The project is kept going by people who choose to support it – if you don't, you get exactly the same apps.

Will it open my Word, Excel and PowerPoint files?

Yes – .docx, .xlsx and .pptx, and it saves them back so others can open them in Microsoft Office. A few advanced things aren't kept yet (for example tracked changes, pivot tables, macros, animations and SmartArt); the app warns you when a file has them, before anything is lost. Very old .doc/.xls/.ppt files need to be saved in the new format first.

Does it work with Photoshop files?

The Photo Editor opens .psd files with their layers and saves them back. Adjustment layers, layer effects and smart objects are loaded as plain pixels.

Is it safe? Windows showed a warning.

The “Windows protected your PC” message appears for any new program that isn't yet known to Microsoft – it doesn't mean something is wrong. The installer doesn't add toolbars, offers or background services, it installs only for your user account, and the uninstaller removes everything. The full source code is included, and you can compare the file's SHA-256 fingerprint with the one on this page.

Do my files get uploaded anywhere?

No. The apps work completely offline. The online tools on this website also run inside your browser – your files are never sent to a server.

Mac or Linux?

Windows only for now. The online tools work in any modern browser, on any computer.

Is it made by Microsoft or Adobe?

No. EthicalApp is independent software. It's compatible with their file formats, but it isn't affiliated with or endorsed by Microsoft or Adobe.

How do I uninstall it?

Settings → Apps → EthicalApp → Uninstall. It removes the apps, shortcuts and right-click entries.
