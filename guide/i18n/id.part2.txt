@@ base-basics
title: Basis data: apa itu basis data dan cara memulai
keywords: basis data database access sqlite mulai templat baru buka tabel rekaman bidang panel navigasi simpan otomatis
---
<p>Basis data menyimpan daftar — kontak, produk, pesanan, tugas — dalam <b>tabel</b>. Setiap baris adalah
<b>rekaman</b> (satu pelanggan), setiap kolom adalah <b>bidang</b> (nama, email…). Tidak seperti lembar kerja, tabel bisa
<a href="#base-relationships">ditautkan</a> (pesanan milik seorang pelanggan), dan Anda bisa bertanya dengan
<a href="#base-queries">kueri</a> serta mencetak <a href="#base-reports">laporan</a>.</p>
<h2>Memulai</h2><p>Halaman awal menawarkan <b>Basis data kosong</b> atau templat siap pakai dengan data contoh:
<b>Kontak</b>, <b>Tugas</b>, <b>Inventaris</b> (dengan kueri stok rendah), <b>Pelanggan &amp; pesanan</b> (tabel tertaut, kueri total pesanan, dan laporan).
Anda juga bisa membuka basis data atau mengimpor Excel/CSV/Access langsung ke basis data baru.</p>
<h2>Jendela</h2><ul>
<li><b>Kiri:</b> panel navigasi — Tabel, Kueri, Laporan. Klik dua kali untuk membuka; klik kanan untuk Tampilan desain, Tampilan formulir, Ganti nama, Hapus, Ekspor, Laporan baru.</li>
<li><b>Kanan:</b> sebuah tab untuk semua yang Anda buka.</li></ul>
<div class="tip">Tidak ada tombol Simpan untuk data — <b>setiap perubahan langsung disimpan</b>, seperti di Access. Gunakan <i>File → Simpan salinan sebagai</i> untuk cadangan.</div>
<p>Basis data adalah satu file <b>.db</b> (format standar SQLite, yang juga bisa dibuka banyak program lain).</p>

@@ base-queries

<p><b>Buat → Kueri</b>. Kueri memilih bidang, menyaring rekaman, dan mengurutkannya — mis. “semua pesanan yang dikirim bulan ini, terbaru dulu”. Kueri tersimpan muncul di bawah <b>Kueri</b> dan selalu menampilkan data terkini.</p>
<h2>Tab Desain</h2><ol>
<li>Pilih <b>tabel utama</b>. Centang <b>tabel terkait</b> untuk memakai bidangnya juga (perlu <a href="#base-relationships">relasi</a>).</li>
<li><b>＋ Tambah bidang</b> (atau <b>Tambah semua bidang</b>), lalu untuk masing-masing: <b>Tampilkan</b>, <b>Urutkan</b>, dan <b>Kriteria</b>.</li>
<li><b>▶ Jalankan</b> untuk melihat hasil; <b>💾 Simpan kueri…</b> untuk menyimpannya.</li></ol>
<h2>Contoh kriteria</h2><table>
<tr><td><code>&gt;100</code>, <code>&lt;=50</code>, <code>&lt;&gt;0</code></td><td>perbandingan</td></tr>
<tr><td><code>"London"</code> atau <code>London</code></td><td>persis ini</td></tr>
<tr><td><code>"London" Or "Paris"</code></td><td>salah satunya</td></tr>
<tr><td><code>Like "A*"</code></td><td>diawali A (<code>*</code> = apa saja, <code>?</code> = satu karakter)</td></tr>
<tr><td><code>Between 1 And 50</code></td><td>sebuah rentang</td></tr>
<tr><td><code>&gt;=#2026-01-01#</code></td><td>tanggal (di antara tanda #)</td></tr>
<tr><td><code>Is Null</code> / <code>Is Not Null</code></td><td>kosong / tidak kosong</td></tr>
<tr><td><code>Yes</code> / <code>No</code></td><td>bidang Ya/Tidak</td></tr></table>
<h2>Total</h2><p>Centang <b>Total</b> untuk mengelompokkan dan menjumlahkan — mis. Kelompokkan menurut pelanggan, Jumlah kuantitas. Kriteria pada Jumlah/Hitung berlaku untuk totalnya.</p>

<h2>Tempat penyimpanan</h2><p><code>%APPDATA%\\Ethical Suite\\Planner\\planner.json</code> (plus cadangan). Tidak pernah diunggah; mencopot aplikasi tetap menyimpannya.</p>

@@ troubleshooting
title: Pemecahan masalah dan Tanya Jawab
keywords: masalah galat tidak berfungsi tidak mau mulai mogok hilang klik kanan font ffmpeg antivirus lambat doc xls ppt bahasa
---
<h3>Aplikasi tidak mau berjalan</h3>
<p>Jalankan lagi penginstal dari <a href="https://ethicalapp.org">ethicalapp.org</a> — ia memperbaiki pemasangan dan menyimpan pengaturan, catatan, serta pengingat Anda.</p>
<h3>“Windows melindungi PC Anda” saat memasang</h3><p>Klik <b>Info selengkapnya → Tetap jalankan</b>. Windows menampilkan ini untuk program baru yang belum dikenalnya. Periksa sidik jari SHA-256 unduhan di situs web jika Anda ingin memastikan keasliannya.</p>
<h3>Item klik kanan tidak ada</h3><p>Jalankan lagi penginstal dan centang opsi klik kanan. Di Windows 11, lihat di bawah <b>Tampilkan opsi lainnya</b>.</p>
<h3>“Jenis file tidak didukung” / file Office lama</h3><p>.doc, .xls, dan .ppt tidak didukung — simpan dulu sebagai .docx/.xlsx/.pptx. Arsip .rar tidak bisa diekstrak.</p>
<h3>Teks terlihat berbeda dari aslinya</h3><p>Font berasal dari PC Anda. Jika dokumen memakai font yang tidak Anda miliki, dipakai font yang mirip. Pasang font itu lalu buka ulang.</p>
<h3>Ada yang hilang setelah menyimpan file Excel/PowerPoint</h3><p>Lihat <a href="#compat">Kompatibilitas file</a> — aplikasi memperingatkan hal yang tidak bisa dipertahankannya. Simpan file aslinya dan gunakan Simpan sebagai.</p>
<h3>Konversi video gagal</h3><p>Pesan galatnya berasal dari FFmpeg. Penyebab umum: file rusak atau masih diunduh, tidak ada audionya (untuk format audio), atau tidak ada gambarnya (untuk format video). Coba MP4 (H.264) dulu — hampir selalu berhasil.</p>
<h3>Peringatan antivirus</h3><p>Sebagian antivirus curiga pada program baru yang belum pernah dilihatnya. Seluruh kode sumber EthicalApp terbuka untuk umum di <a href="https://github.com/CBGGitHub/ethicalapp">GitHub</a>, dan situs web menampilkan sidik jari setiap unduhan.</p>
<h3>Aplikasi memakai bahasa yang salah</h3><p>Klik <b>🌐</b> di bagian bawah jendela EthicalApp — lihat <a href="#language">Mengganti bahasa</a>.</p>
<h3>Lambat</h3><p>Lembar kerja raksasa (lebih dari 100.000 rumus), foto sangat besar dengan banyak lapisan, dan video 4K yang panjang butuh waktu lebih lama. Konverter menunjukkan kemajuan setiap file.</p>

@@ glossary
title: Glosarium
keywords: glosarium istilah arti definisi bitrate crf codec lossless lossy dpi lapisan campuran tempat penampung master
---
<table>
<tr><td><b>Bitrate</b></td><td>Berapa banyak data per detik yang dipakai audio/video (mis. 192k). Lebih tinggi = kualitas lebih baik, file lebih besar.</td></tr>
<tr><td><b>Mode campuran</b></td><td>Cara lapisan berbaur dengan lapisan di bawahnya (Multiply, Screen…).</td></tr>
<tr><td><b>Codec</b></td><td>Metode untuk mengompres audio/video (H.264, H.265, AAC, MP3…).</td></tr>
<tr><td><b>CRF</b></td><td>Pengaturan kualitas video: lebih rendah = kualitas lebih baik, file lebih besar.</td></tr>
<tr><td><b>DPI</b></td><td>Titik per inci — resolusi saat mencetak atau mengubah PDF menjadi gambar.</td></tr>
<tr><td><b>Feather</b></td><td>Tepi seleksi yang lembut dan bertahap.</td></tr>
<tr><td><b>Ratakan</b></td><td>Menggabungkan semua lapisan menjadi satu gambar.</td></tr>
<tr><td><b>Lapisan</b></td><td>Satu lembar dalam tumpukan lembar transparan yang bersama-sama membentuk gambar.</td></tr>
<tr><td><b>Lossless</b></td><td>Kompresi tanpa kehilangan kualitas (PNG, FLAC, ZIP). <b>Lossy</b> membuang detail demi menghemat ruang (JPG, MP3, MP4).</td></tr>
<tr><td><b>Master / tata letak</b></td><td>Dalam file PowerPoint, slide desain tersembunyi yang memberi slide sebenarnya latar belakang, font, dan logo.</td></tr>
<tr><td><b>Rentang bernama</b></td><td>Nama (seperti <code>Prices</code>) yang mewakili sel-sel dalam lembar kerja.</td></tr>
<tr><td><b>Tempat penampung</b></td><td>Kotak kosong “Klik untuk menambah …” pada slide.</td></tr>
<tr><td><b>Sensor</b></td><td>Menghapus isi PDF secara permanen.</td></tr>
<tr><td><b>Toleransi</b></td><td>Seberapa berbeda sebuah warna masih dianggap “mirip” (tongkat ajaib, ember cat).</td></tr></table>
