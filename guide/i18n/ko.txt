<h2>빠른 시작</h2>
<ol><li>처음이신가요? <a href="#setup">앱 설치 및 실행</a>을 참고하세요.</li>
<li>시작 메뉴나 바탕 화면에서 <b>EthicalApp</b>을 여세요: 모든 앱이 한 창에 있습니다. 앱을 클릭하거나 파일을 끌어다 놓으세요.
<b>파일을 마우스 오른쪽 단추로 클릭 → Ethical …(으)로 열기</b>도 사용할 수 있습니다(<a href="#right-click">오른쪽 클릭 메뉴</a> 참고).</li>

<li>AI 도우미에게 맡기고 싶으세요? <a href="#ai-claude">AI(Claude)로 앱 사용하기</a>를 참고하세요.</li></ol>

title: 앱 설치 및 실행
keywords: 설치 설치 프로그램 다운로드 업데이트 제거 시작 메뉴 처음
---
<h2>설치</h2>
<ol><li><a href="https://ethicalapp.org">ethicalapp.org</a>에서 설치 프로그램을 다운로드해 실행하세요. 관리자 암호는 필요 없습니다.</li>
<li>Windows에 “Windows의 PC 보호” 메시지가 나오면 <b>추가 정보 → 실행</b>을 클릭하세요. 아직 잘 알려지지 않은 새 프로그램에서 나타나는 메시지입니다. 웹사이트의 SHA-256 지문으로 다운로드가 진짜인지 확인할 수 있습니다.</li>
<li><b>모두</b>, <b>사무용 앱만</b>을 선택하거나 원하는 앱만 체크하세요.</li>
<li>옵션: 바탕 화면 바로 가기, 오른쪽 클릭 메뉴의 “Ethical …(으)로 열기” 항목, Sticky Notes / Snip / Planner를 Windows와 함께 시작, <b>선택한 앱을 Claude에 연결</b>(<a href="#ai-claude">AI로 앱 사용하기</a> 참고).</li>
<li><b>EthicalApp을 작업 표시줄 / 시작에 고정하도록 도와주기</b>: Windows는 프로그램이 스스로 고정하는 것을 허용하지 않으므로, 실행기가 필요한 두 번의 클릭을 보여 줍니다(작업 표시줄의 아이콘을 마우스 오른쪽 단추로 클릭 → <b>작업 표시줄에 고정</b>, 또는 시작에서 <b>EthicalApp</b>을 마우스 오른쪽 단추로 클릭 → <b>시작 화면에 고정</b>). 실행기의 <b>작업 표시줄 또는 시작에 고정…</b> 링크로 언제든 다시 볼 수 있습니다.</li></ol>
<h2>실행</h2>
<p><b>EthicalApp</b>(시작 메뉴 또는 바탕 화면)을 열면 설치된 모든 앱이 한 창에 나타납니다. 타일을 클릭하거나, <b>파일 열기…</b>(<kbd>Ctrl</kbd>+<kbd>O</kbd>)를 사용하거나, 파일을 끌어다 놓으면 각각 알맞은 앱에서 열립니다. 각 앱은 <b>시작 → EthicalApp</b>에도 있습니다.</p>
<h2>업데이트 및 제거</h2>
<p>업데이트하려면 새 설치 프로그램을 실행하세요. 이전 버전을 바꾸고 설정, 메모, 미리 알림은 그대로 유지합니다. 모두 제거하려면 <b>설정 → 앱 → EthicalApp → 제거</b>(다시 설치할 경우를 대비해 메모와 미리 알림은 PC에 남습니다).</p>
<h2>소스 코드에서(개발자용)</h2>
<p>모든 소스 코드가 공개되어 있습니다 — <a href="#sharing">소스 코드와 직접 빌드하기</a>를 참고하세요.</p>

<p><a href="https://ethicalapp.org">ethicalapp.org</a> 링크를 보내 주세요 — 항상 최신이고 안전한 버전입니다.</p>
<h2>소스에서 설치 프로그램 빌드하기</h2>

<li>앱을 바로 실행하거나(예: <code>.venv\\Scripts\\python apps\\suite_launcher.py</code>) <code>.venv\\Scripts\\python installer\\build.py</code>로 설치 프로그램을 빌드합니다.</li></ol>
<h2>소스의 구성</h2>

<tr><td><code>installer/</code></td><td>Windows 설치 프로그램 빌드</td></tr>

<p>수정한 버전을 배포하면 AGPL에 따라 소스 코드도 공개해야 합니다.</p>

@@ pdf-basics
title: PDF: 열기, 보기, 텍스트 검색
keywords: 확대 축소 미리 보기 페이지 패널 검색 찾기 암호
---
<p>PDF는 <b>파일 → 열기</b>(<kbd>Ctrl</kbd>+<kbd>O</kbd>), 창으로 끌어다 놓기, 또는 마우스 오른쪽 클릭 → <i>Ethical PDF Editor(으)로 열기</i>로 엽니다. 암호가 있는 PDF는 암호를 묻습니다.</p>
<h2>둘러보기</h2><ul>
<li><b>확대/축소:</b> <kbd>Ctrl</kbd>+마우스 휠, 확대/축소 상자, <i>너비에 맞춤</i>(<kbd>Ctrl</kbd>+<kbd>1</kbd>), 실제 크기(<kbd>Ctrl</kbd>+<kbd>0</kbd>).</li>
<li><b>페이지 패널</b>(왼쪽): 미리 보기를 클릭하면 그 페이지로 이동합니다. 페이지 작업을 하려면 <kbd>Ctrl</kbd>/<kbd>Shift</kbd>로 여러 개를 선택하세요. 마우스 오른쪽 클릭으로 페이지 메뉴를 엽니다.</li>
<li><b>페이지로 이동:</b> 페이지 상자에 번호를 입력합니다.</li></ul>
<h2>텍스트 검색</h2><p><b>텍스트 찾기…</b>에 입력하고 <kbd>Enter</kbd>를 누르세요. <kbd>F3</kbd> / <b>다음</b>과 <b>이전</b>으로 결과를 이동합니다(모두 강조 표시, 현재 결과는 주황색).</p>
<h2>텍스트 복사</h2><p><b>선택</b> 도구로 텍스트를 끈 다음 <kbd>Ctrl</kbd>+<kbd>C</kbd>를 누르세요.</p>

<p><b>디자인 → 슬라이드 배경색</b>(이 슬라이드), <b>모든 슬라이드의 배경색</b>, <b>배경 그림</b>.</p>
<p><b>파일 → 슬라이드 크기</b>: 와이드스크린 16:9, 표준 4:3, A4, 정사각형 — 내용이 맞도록 크기가 조정됩니다.</p>
<p><b>파일 → 새로 만들기</b>에서 새 프레젠테이션의 테마를 고를 수 있습니다.</p>
