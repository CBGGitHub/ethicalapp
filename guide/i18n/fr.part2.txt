@@ photo-layers
title: Photos : calques et modes de fusion
keywords: calque nouveau dupliquer fusionner aplatir opacité mode de fusion produit superposition incrustation masquer renommer ordre
---
<p>Les calques sont des feuilles empilées : celles du dessus couvrent celles du dessous. Le panneau <b>Calques</b> les montre en commençant par le haut.</p>
<ul><li>Case = afficher/masquer. Double-clic = renommer. Changez l'ordre avec ▲ ▼.</li>
<li>Boutons : ＋ nouveau, ⧉ dupliquer, ▲▼ déplacer, ⤓ fusionner avec le calque inférieur (<kbd>Ctrl</kbd>+<kbd>E</kbd>), 🗑 supprimer.</li>
<li>Les zones <b>Opacité</b> et <b>mode de fusion</b> au-dessus de la liste s'appliquent au calque actuel.</li>
<li>Menu Calque : fusionner les calques visibles, retourner/faire pivoter le calque, modifier le calque de texte. Menu Image : aplatir.</li></ul>
<h2>Modes de fusion</h2><table>
<tr><td>Produit</td><td>assombrit — idéal pour les ombres et pour poser un dessin au trait sur de la couleur</td></tr>
<tr><td>Superposition / Densité linéaire - (ajout)</td><td>éclaircit — lueurs, effets de lumière</td></tr>
<tr><td>Incrustation / Lumière tamisée / Lumière crue</td><td>ajoute du contraste et de la texture</td></tr>
<tr><td>Obscurcir / Éclaircir</td><td>garde le pixel le plus sombre / le plus clair</td></tr>
<tr><td>Densité couleur - / Densité couleur +</td><td>éclaircissement / assombrissement fort</td></tr>
<tr><td>Différence / Exclusion</td><td>inverse selon le calque du dessous — effets, comparer des images</td></tr></table>
<p>Les calques peuvent avoir n'importe quelle taille et déborder de la zone de travail — un déplacement ne perd jamais de pixels.</p>

<h2>Texte</h2><p>Outil Texte (${K("T")}) → clic → tapez. Choisissez n'importe quelle police, taille (px), gras/italique, couleur, alignement, un <b>contour</b> (épaisseur + couleur) et une <b>ombre portée</b>.
Chaque texte a son propre calque (marqué <b>T</b>). Pour le modifier plus tard : outil Texte → cliquez sur le texte, ou <i>Calque → Modifier le calque de texte</i>.</p>
<div class="warn">Redimensionner, faire pivoter ou retourner un calque de texte le transforme en calque d'image normal (il n'est plus modifiable comme texte).</div>
<h2>Formes</h2><p>Outil Forme (${K("U")}) : choisissez Rectangle, Rectangle arrondi, Ellipse, Ligne ou Flèche. Le remplissage utilise la couleur de premier plan, le contour la couleur d'arrière-plan (réglez son épaisseur, 0 = aucun). Maintenez ${K("Shift")} pour des carrés/cercles parfaits. Chaque forme est placée sur un nouveau calque.</p>

@@ base-basics
title: Base de données : ce qu'est une base de données et comment démarrer
keywords: base de données access sqlite démarrer modèle nouvelle ouvrir table enregistrement champ volet de navigation enregistrement automatique
---
<p>Une base de données range des listes de choses — contacts, produits, commandes, tâches — dans des <b>tables</b>. Chaque ligne est un
<b>enregistrement</b> (un client), chaque colonne un <b>champ</b> (son nom, son e-mail…). Contrairement à une feuille de calcul, les tables peuvent être
<a href="#base-relationships">liées</a> (une commande appartient à un client), et vous pouvez poser des questions avec des
<a href="#base-queries">requêtes</a> et imprimer des <a href="#base-reports">états</a>.</p>
<h2>Démarrer</h2><p>La page d'accueil propose une <b>Base de données vide</b> ou un modèle prêt à l'emploi avec des données d'exemple :
<b>Contacts</b>, <b>Tâches</b>, <b>Inventaire</b> (avec une requête Stock bas), <b>Clients et commandes</b> (tables liées, une requête Totaux des commandes et un état).
Vous pouvez aussi ouvrir une base ou importer Excel/CSV/Access directement dans une nouvelle.</p>
<h2>La fenêtre</h2><ul>
<li><b>À gauche :</b> le volet de navigation — Tables, Requêtes, États. Double-cliquez pour ouvrir ; clic droit pour Mode Création, Mode Formulaire, Renommer, Supprimer, Exporter, Nouvel état.</li>
<li><b>À droite :</b> un onglet pour tout ce que vous ouvrez.</li></ul>
<div class="tip">Il n'y a pas de bouton Enregistrer pour les données — <b>chaque modification est enregistrée aussitôt</b>, comme dans Access. Utilisez <i>Fichier → Enregistrer une copie sous</i> pour les sauvegardes.</div>
<p>Une base de données est un seul fichier <b>.db</b> (le format standard SQLite, que beaucoup d'autres outils savent ouvrir).</p>

<h2>Mode Feuille de données</h2><p>S'ouvre comme une feuille de calcul. Cliquez sur une cellule et tapez ; appuyez sur <kbd>Entrée</kbd> pour l'enregistrer.</p><ul>

@@ base-queries
title: Base de données : requêtes (interroger vos données)
keywords: requête création critères tri totaux somme compte regroupement sql vue jointure liée
---
<p><b>Créer → Requête</b>. Une requête choisit des champs, filtre des enregistrements et les trie — p. ex. « toutes les commandes expédiées ce mois-ci, les plus récentes d'abord ». Les requêtes enregistrées apparaissent sous <b>Requêtes</b> et montrent toujours les données actuelles.</p>
<h2>Onglet Création</h2><ol>
<li>Choisissez la <b>table principale</b>. Cochez des <b>tables liées</b> pour utiliser aussi leurs champs (il faut une <a href="#base-relationships">relation</a>).</li>
<li><b>＋ Ajouter un champ</b> (ou <b>Ajouter tous les champs</b>), puis pour chacun : <b>Afficher</b>, <b>Tri</b> et <b>Critères</b>.</li>
<li><b>▶ Exécuter</b> pour voir les résultats ; <b>💾 Enregistrer la requête…</b> pour la garder.</li></ol>
<h2>Exemples de critères</h2><table>
<tr><td><code>&gt;100</code>, <code>&lt;=50</code>, <code>&lt;&gt;0</code></td><td>comparaisons</td></tr>
<tr><td><code>"London"</code> ou <code>London</code></td><td>exactement cela</td></tr>
<tr><td><code>"London" Or "Paris"</code></td><td>l'un ou l'autre</td></tr>
<tr><td><code>Like "A*"</code></td><td>commence par A (<code>*</code> = n'importe quoi, <code>?</code> = un caractère)</td></tr>
<tr><td><code>Between 1 And 50</code></td><td>un intervalle</td></tr>
<tr><td><code>&gt;=#2026-01-01#</code></td><td>dates (entre signes #)</td></tr>
<tr><td><code>Is Null</code> / <code>Is Not Null</code></td><td>vide / non vide</td></tr>
<tr><td><code>Yes</code> / <code>No</code></td><td>champs Oui/Non</td></tr></table>
<h2>Totaux</h2><p>Cochez <b>Totaux</b> pour regrouper et additionner — p. ex. Regroupement par client, Somme de la quantité. Les critères sur une Somme/un Compte s'appliquent aux totaux.</p>
<h2>Onglet SQL</h2><p>Affiche la requête en SQL (le langage standard des bases de données) — vous pouvez la modifier directement. <i>Base de données → Console SQL</i> permet d'exécuter n'importe quel SQL ; les commandes qui modifient des données demandent d'abord.</p>

@@ base-relationships
title: Base de données : relations (lier des tables)
keywords: relation lien clé étrangère un à plusieurs parent enfant suppression en cascade diagramme
---
<p>Une relation dit « chaque enregistrement <b>enfant</b> appartient à un enregistrement <b>parent</b> » — chaque commande appartient à un client, chaque produit à une catégorie.</p>
<ol><li>Donnez à la table enfant un champ <b>Nombre entier</b> qui contiendra l'identifiant du parent (p. ex. <i>Customer ID</i> dans Commandes).</li>
<li><b>Base de données → Relations</b> : choisissez la table parente et son identifiant, la table enfant et son champ qui « pointe vers », puis <b>＋ Ajouter une relation</b>.</li></ol>
<p>Ce que vous obtenez :</p><ul>
<li>Le champ enfant affiche une <b>liste déroulante des noms du parent</b> dans les feuilles de données et les formulaires.</li>
<li>Les enregistrements ne peuvent pas pointer vers un parent qui n'existe pas, et un parent qui a des enfants ne peut pas être supprimé par erreur…</li>
<li>…sauf si vous avez coché <b>suppression en cascade</b> : alors supprimer un parent supprime aussi ses enfants (p. ex. supprimer une commande supprime ses lignes).</li>
<li>Les requêtes peuvent combiner des champs de tables liées.</li></ul>
<p>La fenêtre montre un diagramme de toutes les tables avec des traits entre les champs liés (1 ── ∞).</p>

<p><b>Ethical Planner</b> vous rappelle les choses à l'heure — « prendre mes compléments tous les jours à 8:00 », « dentiste demain à 14:30 »,

@@ troubleshooting
title: Dépannage et FAQ
keywords: problème erreur ne marche pas ne démarre pas plantage manquant clic droit police ffmpeg antivirus lent doc xls ppt langue
---
<h3>Une application ne démarre pas</h3>
<p>Relancez le programme d'installation depuis <a href="https://ethicalapp.org">ethicalapp.org</a> — il répare l'installation et garde vos réglages, notes et rappels.</p>
<h3>« Windows a protégé votre ordinateur » à l'installation</h3><p>Cliquez sur <b>Informations complémentaires → Exécuter quand même</b>. Windows affiche cela pour les nouveaux programmes qu'il ne connaît pas encore. Vérifiez l'empreinte SHA-256 du téléchargement sur le site si vous voulez être sûr qu'il est authentique.</p>
<h3>Les entrées du clic droit manquent</h3><p>Relancez le programme d'installation et cochez l'option du clic droit. Sous Windows 11, regardez dans <b>Afficher plus d'options</b>.</p>
<h3>« Type de fichier non pris en charge » / anciens fichiers Office</h3><p>.doc, .xls et .ppt ne sont pas pris en charge — enregistrez-les d'abord en .docx/.xlsx/.pptx. Les archives .rar ne peuvent pas être extraites.</p>
<h3>Le texte n'a pas le même aspect que l'original</h3><p>Les polices viennent de votre PC. Si un document utilise une police que vous n'avez pas, une police ressemblante est utilisée. Installez la police et rouvrez le document.</p>
<h3>Il manque quelque chose après l'enregistrement d'un fichier Excel/PowerPoint</h3><p>Voir <a href="#compat">Compatibilité des fichiers</a> — l'application prévient de ce qu'elle ne peut pas conserver. Gardez l'original et utilisez Enregistrer sous.</p>
<h3>Une conversion vidéo a échoué</h3><p>Le message d'erreur vient de FFmpeg. Causes fréquentes : le fichier est abîmé ou encore en cours de téléchargement, il n'a pas de son (pour les formats audio) ou pas d'image (pour les formats vidéo). Essayez d'abord MP4 (H.264) — il marche avec presque tout.</p>
<h3>Alerte de l'antivirus</h3><p>Certains antivirus se méfient des nouveaux programmes qu'ils n'ont jamais vus. Tout le code source d'EthicalApp est public sur <a href="https://github.com/CBGGitHub/ethicalapp">GitHub</a>, et le site affiche l'empreinte de chaque téléchargement.</p>
<h3>Les applications sont dans la mauvaise langue</h3><p>Cliquez sur <b>🌐</b> en bas de la fenêtre EthicalApp — voir <a href="#language">Changer de langue</a>.</p>
<h3>C'est lent</h3><p>Les feuilles de calcul énormes (plus de 100 000 formules), les très grandes photos avec beaucoup de calques et les longues vidéos 4K prennent plus de temps. Le convertisseur affiche la progression de chaque fichier.</p>

@@ glossary
title: Glossaire
keywords: glossaire termes signification définition débit crf codec sans perte avec perte ppp calque fusion espace réservé masque
---
<table>
<tr><td><b>Débit</b></td><td>La quantité de données par seconde utilisée par l'audio/la vidéo (p. ex. 192k). Plus élevé = meilleure qualité, fichier plus gros.</td></tr>
<tr><td><b>Mode de fusion</b></td><td>La façon dont un calque se mélange aux calques du dessous (Produit, Superposition…).</td></tr>
<tr><td><b>Codec</b></td><td>La méthode utilisée pour compresser l'audio/la vidéo (H.264, H.265, AAC, MP3…).</td></tr>
<tr><td><b>CRF</b></td><td>Réglage de qualité vidéo : plus bas = meilleure qualité, fichier plus gros.</td></tr>
<tr><td><b>PPP (DPI)</b></td><td>Points par pouce — la résolution à l'impression ou quand on transforme des PDF en images.</td></tr>
<tr><td><b>Contour progressif</b></td><td>Un bord doux et progressif sur une sélection.</td></tr>
<tr><td><b>Aplatir</b></td><td>Fusionner tous les calques en une seule image.</td></tr>
<tr><td><b>Calque</b></td><td>Une feuille dans une pile de feuilles transparentes qui forment une image.</td></tr>
<tr><td><b>Sans perte</b></td><td>Compression sans perte de qualité (PNG, FLAC, ZIP). <b>Avec perte</b> : on supprime des détails pour gagner de la place (JPG, MP3, MP4).</td></tr>
<tr><td><b>Masque / disposition</b></td><td>Dans les fichiers PowerPoint, les diapositives de modèle cachées qui donnent aux vraies diapositives leur arrière-plan, leurs polices et leur logo.</td></tr>
<tr><td><b>Plage nommée</b></td><td>Un nom (comme <code>Prices</code>) qui désigne des cellules d'une feuille de calcul.</td></tr>
<tr><td><b>Espace réservé</b></td><td>Un cadre vide « Cliquez pour ajouter … » sur une diapositive.</td></tr>
<tr><td><b>Caviarder</b></td><td>Supprimer définitivement du contenu d'un PDF.</td></tr>
<tr><td><b>Tolérance</b></td><td>À quel point une couleur peut être différente tout en comptant comme « proche » (baguette magique, pot de peinture).</td></tr></table>
