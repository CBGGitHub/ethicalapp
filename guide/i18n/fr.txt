@@ setup
title: Installer et lancer les applications
keywords: installer installation télécharger mise à jour désinstaller menu démarrer première fois
---
<h2>Installer</h2>
<ol><li>Téléchargez le programme d'installation sur <a href="https://ethicalapp.org">ethicalapp.org</a> et lancez-le. Aucun mot de passe administrateur n'est nécessaire.</li>
<li>Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur <b>Informations complémentaires → Exécuter quand même</b>. Ce message apparaît pour les nouveaux programmes encore peu connus ; vous pouvez vérifier que votre téléchargement est authentique grâce à l'empreinte SHA-256 affichée sur le site.</li>
<li>Choisissez <b>Tout</b>, <b>Applications de bureautique seulement</b>, ou cochez exactement les applications voulues.</li>
<li>Options : raccourcis sur le bureau, entrées « Ouvrir avec Ethical … » au clic droit, démarrage de Sticky Notes / Snip / Planner avec Windows, et <b>Connecter les applications choisies à Claude</b> (voir <a href="#ai-claude">Utiliser les applications avec l'IA</a>).</li>
<li><b>M'aider à épingler EthicalApp à la barre des tâches / Démarrer</b> : Windows ne laisse pas les programmes s'épingler eux-mêmes, le lanceur montre donc les deux clics nécessaires (clic droit sur son icône dans la barre des tâches → <b>Épingler à la barre des tâches</b> ; ou dans Démarrer, clic droit sur <b>EthicalApp</b> → <b>Épingler à l'écran de démarrage</b>). Le lien <b>Épingler à la barre des tâches ou à Démarrer…</b> du lanceur les réaffiche à tout moment.</li></ol>
<h2>Lancer</h2>
<p>Ouvrez <b>EthicalApp</b> (menu Démarrer ou bureau) pour avoir une fenêtre avec toutes vos applications installées : cliquez sur une vignette, utilisez <b>Ouvrir un fichier…</b> (<kbd>Ctrl</kbd>+<kbd>O</kbd>) ou déposez-y des fichiers, et chacun s'ouvre dans la bonne application. Chaque application se trouve aussi dans <b>Démarrer → EthicalApp</b>.</p>
<h2>Mettre à jour et désinstaller</h2>
<p>Pour mettre à jour, lancez un programme d'installation plus récent : il remplace l'ancienne version et conserve vos réglages, notes et rappels. Pour tout supprimer : <b>Paramètres → Applications → EthicalApp → Désinstaller</b> (vos notes et rappels restent sur le PC au cas où vous réinstalleriez).</p>
<h2>Depuis le code source (développeurs)</h2>
<p>Tout le code source est public — voir <a href="#sharing">Code source et compilation par vous-même</a>.</p>

@@ pdf-basics
title: PDF : ouvrir, afficher et rechercher du texte
keywords: zoom miniatures pages panneau rechercher trouver mot de passe
---
<p>Ouvrez un PDF avec <b>Fichier → Ouvrir</b> (<kbd>Ctrl</kbd>+<kbd>O</kbd>), en le faisant glisser dans la fenêtre, ou par clic droit → <i>Ouvrir avec Ethical PDF Editor</i>. Les PDF protégés par mot de passe le demandent.</p>
<h2>Se déplacer</h2><ul>
<li><b>Zoom :</b> <kbd>Ctrl</kbd>+molette, la zone de zoom, <i>Ajuster à la largeur</i> (<kbd>Ctrl</kbd>+<kbd>1</kbd>), taille réelle (<kbd>Ctrl</kbd>+<kbd>0</kbd>).</li>
<li><b>Panneau des pages</b> (à gauche) : cliquez sur une miniature pour y aller. Sélectionnez-en plusieurs avec <kbd>Ctrl</kbd>/<kbd>Maj</kbd> pour agir sur les pages. Clic droit pour le menu Pages.</li>
<li><b>Aller à une page :</b> tapez un numéro dans la zone Page.</li></ul>
<h2>Rechercher du texte</h2><p>Tapez dans <b>Rechercher du texte…</b> et appuyez sur <kbd>Entrée</kbd> ; <kbd>F3</kbd> / <b>Suivant</b> et <b>Préc.</b> parcourent les résultats (tous surlignés, l'actuel en orange).</p>
<h2>Copier du texte</h2><p>Avec l'outil <b>Sélection</b>, faites glisser sur le texte, puis <kbd>Ctrl</kbd>+<kbd>C</kbd>.</p>

@@ pdf-edit-text
title: PDF : modifier le texte existant et ajouter du texte
keywords: modifier texte changer mots police faute ajouter texte
---
<h2>Changer un texte déjà présent dans le PDF</h2><ol>
<li>Choisissez l'outil <b>Modifier le texte</b>.</li><li>Cliquez sur la ligne à changer.</li>
<li>Une boîte affiche le texte de la ligne, la police, la taille, gras/italique et la couleur — changez ce que vous voulez et cliquez sur OK.</li></ol>
<p>L'application détecte la police du PDF et choisit la police correspondante installée sur votre PC (p. ex. Calibri, Times New Roman). Si cette police n'est pas installée, elle en utilise une qui lui ressemble.</p>
<div class="warn">La modification se fait ligne par ligne. Le texte pivoté ou vertical ne peut pas être modifié.</div>
<h2>Ajouter du texte</h2><p>Choisissez <b>Ajouter du texte</b>, cliquez à l'endroit voulu, tapez, choisissez n'importe quelle police installée. Il devient du vrai texte de la page — vous pourrez le changer plus tard avec <b>Modifier le texte</b>.</p>

@@ pdf-forms-sign

<h2>Formulaires</h2><p>Les champs de formulaire sont teintés de bleu clair (désactivez-le avec <i>Affichage → Mettre en évidence les champs du formulaire</i>). Avec l'outil <b>Sélection</b>, cliquez sur un champ : les champs texte demandent du texte, les cases se cochent et se décochent, les listes déroulantes affichent leurs choix.</p>

<li>Cliquez sur la page pour la placer. Cliquez encore pour en placer d'autres copies. Déplacez-la plus tard avec <b>Sélection</b>.</li></ol>

<p>Ethical Document Editor affiche votre document en vraies pages — des feuilles blanches avec marges, exactement comme à l'impression. La barre d'état indique la page où vous êtes et le nombre de mots.</p>
<h2>Styles</h2><p>La première zone de la barre de mise en forme définit le style du paragraphe : <b>Normal, Titre, Titre 1–4</b>. Appuyer sur <kbd>Entrée</kbd> après un titre revient à Normal, comme dans Word. Les titres sont enregistrés comme de vrais titres Word.</p>
<h2>Polices</h2><p>Toutes les polices installées sur votre PC sont disponibles. Les nouveaux documents utilisent Calibri 11 (ou Arial si Calibri n'est pas installée).</p>

<p><b>Ouvre et enregistre les .pptx.</b> Les présentations importées s'affichent comme dans PowerPoint : l'application lit les masques et dispositions de la présentation (couleurs du thème, polices, arrière-plans, logos, styles de puces). À l'enregistrement, les masques, dispositions et thème d'origine sont conservés, donc elle reste correcte dans PowerPoint.</p>
<p><b>Exporter :</b> PDF (net, texte sélectionnable), images PNG (1920 px de large), Imprimer.</p>
<p><b>Pas encore conservé :</b> graphiques, SmartArt, vidéo/audio, animations et transitions (vous êtes averti). Les dégradés s'affichent d'une seule couleur. Pas encore de mode présentateur ni de correcteur orthographique.</p>
