<b>registro</b> (um cliente), cada coluna um <b>campo</b> (o nome, o e-mail…). Diferente de uma planilha, as tabelas podem ser
<a href="#base-relationships">ligadas</a> (um pedido pertence a um cliente), e você pode fazer perguntas com
<a href="#base-queries">consultas</a> e imprimir <a href="#base-reports">relatórios</a>.</p>
<h2>Começar</h2><p>A página inicial oferece um <b>Banco de dados em branco</b> ou um modelo pronto com dados de exemplo:
<b>Contatos</b>, <b>Tarefas</b>, <b>Estoque</b> (com uma consulta de estoque baixo), <b>Clientes e pedidos</b> (tabelas ligadas, uma consulta de totais de pedidos e um relatório).
Você também pode abrir um banco de dados ou importar Excel/CSV/Access direto para um novo.</p>
<h2>A janela</h2><ul>
<li><b>Esquerda:</b> o painel de navegação — Tabelas, Consultas, Relatórios. Clique duas vezes para abrir; botão direito para Modo Design, Modo Formulário, Renomear, Excluir, Exportar, Novo relatório.</li>
<li><b>Direita:</b> abas para tudo o que você abre.</li></ul>
<div class="tip">Não há botão Salvar para os dados — <b>toda mudança é salva na hora</b>, como no Access. Use <i>Arquivo → Salvar uma cópia como</i> para backups.</div>
<p>Um banco de dados é um único arquivo <b>.db</b> (o formato padrão SQLite, que muitas outras ferramentas também abrem).</p>

<h2>Modo Folha de dados</h2><p>Abre como uma planilha. Clique numa célula e digite; pressione <kbd>Enter</kbd> para salvar.</p><ul>

<p><b>Criar → Consulta</b>. Uma consulta escolhe campos, filtra registros e os classifica — ex.: “todos os pedidos enviados este mês, os mais novos primeiro”. As consultas salvas aparecem em <b>Consultas</b> e sempre mostram os dados atuais.</p>
<h2>Aba Design</h2><ol>
<li>Escolha a <b>tabela principal</b>. Marque <b>tabelas relacionadas</b> para usar os campos delas também (precisa de um <a href="#base-relationships">relacionamento</a>).</li>
<li><b>＋ Adicionar campo</b> (ou <b>Adicionar todos os campos</b>), e para cada um: <b>Mostrar</b>, <b>Classificar</b> e <b>Critérios</b>.</li>
<li><b>▶ Executar</b> para ver os resultados; <b>💾 Salvar consulta…</b> para guardá-la.</li></ol>
<h2>Exemplos de critérios</h2><table>
<tr><td><code>&gt;100</code>, <code>&lt;=50</code>, <code>&lt;&gt;0</code></td><td>comparações</td></tr>
<tr><td><code>"London"</code> ou <code>London</code></td><td>exatamente isso</td></tr>
<tr><td><code>"London" Or "Paris"</code></td><td>um ou outro</td></tr>
<tr><td><code>Like "A*"</code></td><td>começa com A (<code>*</code> = qualquer coisa, <code>?</code> = um caractere)</td></tr>
<tr><td><code>Between 1 And 50</code></td><td>um intervalo</td></tr>
<tr><td><code>&gt;=#2026-01-01#</code></td><td>datas (entre sinais #)</td></tr>
<tr><td><code>Is Null</code> / <code>Is Not Null</code></td><td>vazio / não vazio</td></tr>
<tr><td><code>Yes</code> / <code>No</code></td><td>campos Sim/Não</td></tr></table>
<h2>Totais</h2><p>Marque <b>Totais</b> para agrupar e somar — ex.: Agrupar por cliente, Soma da quantidade. Critérios numa Soma/Contagem valem para os totais.</p>
<h2>Aba SQL</h2><p>Mostra a consulta como SQL (a linguagem padrão de banco de dados) — você pode editá-la direto. <i>Banco de dados → Console SQL</i> deixa executar qualquer SQL; comandos que mudam dados perguntam antes.</p>

@@ base-relationships
title: Banco de dados: relacionamentos (ligar tabelas)
keywords: relacionamento ligação chave estrangeira um para muitos pai filho exclusão em cascata diagrama
---
<p>Um relacionamento diz “cada registro <b>filho</b> pertence a um registro <b>pai</b>” — cada pedido pertence a um cliente, cada produto a uma categoria.</p>
<ol><li>Dê à tabela filha um campo <b>Número inteiro</b> que vai guardar o ID do pai (ex.: <i>Customer ID</i> em Pedidos).</li>
<li><b>Banco de dados → Relacionamentos</b>: escolha a tabela pai e o ID dela, a tabela filha e o campo que “aponta”, e <b>＋ Adicionar relacionamento</b>.</li></ol>
<p>O que você ganha:</p><ul>
<li>O campo filho mostra uma <b>lista suspensa de nomes do pai</b> nas folhas de dados e nos formulários.</li>
<li>Os registros não podem apontar para um pai que não existe, e um pai com filhos não pode ser apagado sem querer…</li>
<li>…a menos que você marque <b>exclusão em cascata</b>: aí apagar um pai também apaga os filhos (ex.: apagar um pedido apaga as linhas dele).</li>
<li>As consultas podem combinar campos de tabelas relacionadas.</li></ul>
<p>A janela mostra um diagrama de todas as tabelas com linhas entre os campos relacionados (1 ── ∞).</p>

<p>O <b>Ethical Planner</b> lembra você das coisas na hora — “tomar os suplementos todo dia às 8:00”, “dentista amanhã às 14:30”,

<li><b>Relógio:</b> os horários seguem o relógio do seu PC. Escolha <b>⋯ → Relógio → 12 horas (8:00 PM)</b> ou <b>24 horas (20:00)</b> – por padrão o Planner usa o mesmo que o Windows.</li></ul>

@@ troubleshooting
title: Solução de problemas e perguntas frequentes
keywords: problema erro não funciona não abre trava falta botão direito fonte ffmpeg antivírus lento doc xls ppt idioma
---
<h3>Um aplicativo não abre</h3>
<p>Execute de novo o instalador de <a href="https://ethicalapp.org">ethicalapp.org</a> — ele repara a instalação e mantém as suas configurações, notas e lembretes.</p>
<h3>“O Windows protegeu o computador” ao instalar</h3><p>Clique em <b>Mais informações → Executar assim mesmo</b>. O Windows mostra isso para programas novos que ele ainda não conhece. Confira a impressão digital SHA-256 do download no site se quiser ter certeza de que é autêntico.</p>
<h3>Os itens do botão direito sumiram</h3><p>Execute o instalador de novo e marque a opção do botão direito. No Windows 11, procure em <b>Mostrar mais opções</b>.</p>
<h3>“Tipo de arquivo não compatível” / arquivos antigos do Office</h3><p>.doc, .xls e .ppt não são compatíveis — salve-os primeiro como .docx/.xlsx/.pptx. Arquivos .rar não podem ser extraídos.</p>
<h3>O texto ficou diferente do original</h3><p>As fontes vêm do seu PC. Se um documento usa uma fonte que você não tem, é usada uma parecida. Instale a fonte e abra de novo.</p>
<h3>Algo sumiu depois de salvar um arquivo do Excel/PowerPoint</h3><p>Veja <a href="#compat">Compatibilidade de arquivos</a> — o aplicativo avisa sobre o que não consegue manter. Guarde o original e use Salvar como.</p>
<h3>Uma conversão de vídeo falhou</h3><p>A mensagem de erro vem do FFmpeg. Causas comuns: o arquivo está danificado ou ainda baixando, não tem som (para formatos de áudio) ou não tem imagem (para formatos de vídeo). Tente primeiro MP4 (H.264) — funciona com quase tudo.</p>
<h3>Aviso do antivírus</h3><p>Alguns antivírus desconfiam de programas novos que ainda não viram. Todo o código-fonte do EthicalApp é público no <a href="https://github.com/CBGGitHub/ethicalapp">GitHub</a>, e o site mostra a impressão digital de cada download.</p>
<h3>Os aplicativos estão no idioma errado</h3><p>Clique em <b>🌐</b> embaixo na janela do EthicalApp — veja <a href="#language">Mudar o idioma</a>.</p>
<h3>Está lento</h3><p>Planilhas enormes (mais de 100 mil fórmulas), fotos muito grandes com muitas camadas e vídeos 4K longos demoram mais. O conversor mostra o progresso de cada arquivo.</p>

<table>
<tr><td><b>Taxa de bits</b></td><td>Quantos dados por segundo o áudio/vídeo usa (ex.: 192k). Maior = melhor qualidade, arquivo maior.</td></tr>
<tr><td><b>Modo de mesclagem</b></td><td>Como uma camada se mistura com as camadas de baixo (Multiplicação, Divisão…).</td></tr>
<tr><td><b>Codec</b></td><td>O método usado para comprimir áudio/vídeo (H.264, H.265, AAC, MP3…).</td></tr>
<tr><td><b>CRF</b></td><td>Ajuste de qualidade do vídeo: menor = melhor qualidade, arquivo maior.</td></tr>
<tr><td><b>DPI</b></td><td>Pontos por polegada — a resolução ao imprimir ou ao transformar PDFs em imagens.</td></tr>
<tr><td><b>Suavizar</b></td><td>Uma borda suave e gradual numa seleção.</td></tr>
<tr><td><b>Achatar</b></td><td>Juntar todas as camadas numa imagem só.</td></tr>
<tr><td><b>Camada</b></td><td>Uma folha numa pilha de folhas transparentes que formam uma imagem.</td></tr>
<tr><td><b>Sem perdas</b></td><td>Compressão sem perda de qualidade (PNG, FLAC, ZIP). <b>Com perdas</b> descarta detalhes para economizar espaço (JPG, MP3, MP4).</td></tr>
<tr><td><b>Mestre / layout</b></td><td>Nos arquivos do PowerPoint, os slides de design ocultos que dão aos slides de verdade o fundo, as fontes e o logotipo.</td></tr>
<tr><td><b>Intervalo nomeado</b></td><td>Um nome (como <code>Prices</code>) que representa células numa planilha.</td></tr>
<tr><td><b>Espaço reservado</b></td><td>Uma caixa vazia “Clique para adicionar …” num slide.</td></tr>
<tr><td><b>Censurar</b></td><td>Remover conteúdo de um PDF para sempre.</td></tr>
<tr><td><b>Tolerância</b></td><td>Quanto uma cor pode ser diferente e ainda contar como “parecida” (varinha mágica, balde de tinta).</td></tr></table>
