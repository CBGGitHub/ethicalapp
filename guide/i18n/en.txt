@@ setup
title: Installing & starting the apps
keywords: install setup installer download update uninstall start menu launcher first time
---
<h2>Install</h2>
<ol><li>Download the installer from <a href="https://ethicalapp.org">ethicalapp.org</a> and run it. No administrator password needed.</li>
<li>If Windows says “Windows protected your PC”, click <b>More info → Run anyway</b>. That message appears for new programs that aren't widely known yet; you can check that your download is genuine with the SHA-256 fingerprint shown on the website.</li>
<li>Choose <b>Everything</b>, <b>Office apps only</b>, or tick exactly the apps you want.</li>
<li>Options: desktop shortcuts, right-click “Open with Ethical …” entries, starting Sticky Notes / Snip / Planner with Windows, and <b>Connect the chosen apps to Claude</b> (see <a href="#ai-claude">Using the apps with AI</a>).</li>
<li><b>Help me pin EthicalApp to the taskbar / Start</b>: Windows doesn't let programs pin themselves, so the launcher shows the two-click steps (right-click its taskbar icon → <b>Pin to taskbar</b>; or in Start right-click <b>EthicalApp</b> → <b>Pin to Start</b>). The launcher's <b>Pin to taskbar or Start…</b> link shows them again any time.</li></ol>
<h2>Start</h2>
<p>Open <b>EthicalApp</b> (Start menu or desktop) for one window with all your installed apps: click a tile, use <b>Open a file…</b> (<kbd>Ctrl</kbd>+<kbd>O</kbd>), or drop files on it and each opens in the right app. Every app is also in <b>Start → EthicalApp</b>.</p>
<h2>Update & uninstall</h2>
<p>To update, run a newer installer: it replaces the old version and keeps your settings, notes and reminders. To remove everything: <b>Settings → Apps → EthicalApp → Uninstall</b> (your notes and reminders stay on the PC in case you reinstall).</p>
<h2>From source (developers)</h2>
<p>The full source code is public — see <a href="#sharing">Source code & building it yourself</a>.</p>

@@ pdf-basics
title: PDF: opening, viewing & finding text
keywords: zoom thumbnails pages panel search find password
---
<p>Open a PDF with <b>File → Open</b> (<kbd>Ctrl</kbd>+<kbd>O</kbd>), by dragging it into the window, or right-click → <i>Open with Ethical PDF Editor</i>. Password-protected PDFs ask for the password.</p>
<h2>Moving around</h2><ul>
<li><b>Zoom:</b> <kbd>Ctrl</kbd>+mouse wheel, the zoom box, <i>Fit Width</i> (<kbd>Ctrl</kbd>+<kbd>1</kbd>), actual size (<kbd>Ctrl</kbd>+<kbd>0</kbd>).</li>
<li><b>Pages panel</b> (left): click a thumbnail to jump. Select several with <kbd>Ctrl</kbd>/<kbd>Shift</kbd> for page operations. Right-click for the Pages menu.</li>
<li><b>Go to page:</b> type a number in the Page box.</li></ul>
<h2>Find text</h2><p>Type in <b>Find text…</b> and press <kbd>Enter</kbd>; <kbd>F3</kbd> / <b>Next</b> and <b>Prev</b> step through matches (all highlighted, current one orange).</p>
<h2>Copy text</h2><p>With the <b>Select</b> tool, drag across text, then <kbd>Ctrl</kbd>+<kbd>C</kbd>.</p>

@@ pdf-edit-text
title: PDF: editing existing text & adding text
keywords: edit text change words font typo add text
---
<h2>Change text that's already in the PDF</h2><ol>
<li>Choose the <b>Edit Text</b> tool.</li><li>Click on the line you want to change.</li>
<li>A box shows the line's text, font, size, bold/italic and colour — change anything and press OK.</li></ol>
<p>The app detects the PDF's font and picks the matching font installed on your PC (e.g. Calibri, Times New Roman). If that font isn't installed it uses a look-alike.</p>
<div class="warn">Editing works one line at a time. Rotated/vertical text can't be edited.</div>
<h2>Add new text</h2><p>Choose <b>Add Text</b>, click where it should go, type, pick any installed font. It becomes real page text — later you can change it with <b>Edit Text</b>.</p>

<p>A database keeps lists of things — contacts, products, orders, tasks — in <b>tables</b>. Each row is a
<b>record</b> (one customer), each column a <b>field</b> (their name, email…). Unlike a spreadsheet, tables can be

<a href="#base-queries">queries</a> and print <a href="#base-reports">reports</a>.</p>
<h2>Start</h2><p>The start page offers a <b>Blank database</b> or a ready-made template with sample data:
<b>Contacts</b>, <b>Tasks</b>, <b>Inventory</b> (with a Low Stock query), <b>Customers & Orders</b> (linked tables, an Order Totals query and a report).
You can also open a database or import Excel/CSV/Access straight into a new one.</p>
<h2>The window</h2><ul>
<li><b>Left:</b> the navigation pane — Tables, Queries, Reports. Double-click to open; right-click for Design View, Form View, Rename, Delete, Export, New Report.</li>
<li><b>Right:</b> tabs for everything you open.</li></ul>
<div class="tip">There's no Save button for data — <b>every change is saved immediately</b>, like in Access. Use <i>File → Save a Copy As</i> for backups.</div>
<p>A database is a single <b>.db</b> file (the standard SQLite format, which many other tools can open too).</p>

<li>The card stays until you click <b>Done</b>/<b>OK</b>, <b>Snooze</b> (5 minutes … tomorrow morning) or ✕. It shows even when Windows' Focus Assist is on.</li>
<li>Was the PC off or asleep? Anything you missed in the last 12 hours pops up next time, marked <i>missed</i>.</li>
<li>Each pop-up plays a soft chime (Planner's own sound, so it works even if Windows sounds are muted for notifications). Try it: <b>⋯ → Test a reminder pop-up</b>. Turn the sound on/off in <b>⋯</b>.</li>
<li><b>Clock:</b> times follow your PC's clock. Choose <b>⋯ → Clock → 12-hour (8:00 PM)</b> or <b>24-hour (20:00)</b> – by default Planner uses whatever Windows uses.</li></ul>
<h2>The list</h2><ul>
<li>Shows the selected day and the 6 days after it. Click a date in the calendar to look ahead; <b>Today</b> (${K("Ctrl T")}) jumps back.</li>
<li>Tick the box to mark a reminder done for that day (it's crossed out). Overdue ones are red.</li>
<li>Right-click an item: Edit, Mark done / Not done, <b>Skip just this one</b> (for a repeating item), Delete.</li>
<li>Bold days in the calendar have events or less-frequent reminders. <b>Next up</b> shows the next alert.</li></ul>
<h2>Keep it running</h2><p>Reminders can only pop up while Planner runs, so closing the window keeps it in the tray (bottom-right of the taskbar).
On first start it asks to <b>start with Windows</b> — say yes (or tick it in the installer or <b>⋯</b>). <b>Quit Ethical Planner</b> in the tray menu stops it.</p>
<h2>Where it's kept</h2><p><code>%APPDATA%\\Ethical Suite\\Planner\\planner.json</code> (plus a backup). Never uploaded; uninstalling keeps it.</p>
<h2>With AI</h2><p>If you connected Planner to Claude: “remind me to take my vitamins every day at 8”, “what's coming up this week?”,
“I took my pills” (ticks it off), “move the dentist to Thursday at 3”.</p>

<p><b>Ethical Snip</b> takes a picture of your screen — all of it, one window, or just the part you choose — and lets you
draw on it before you copy or save it.</p>
<h2>Taking a snip</h2><ul>
<li>Press ${K("Ctrl PrtScn")} anywhere (while Snip is running — it waits in the tray, bottom-right of the taskbar), click <b>✂ New snip</b> (${K("Ctrl N")}), or use the tray icon.</li>
<li>The screen freezes and dims. Choose at the top: <b>Rectangle</b> (drag an area), <b>Window</b> (click a window), <b>Full screen</b> (click) or <b>Free-form</b> (draw around something).
Keys: <kbd>R</kbd> <kbd>W</kbd> <kbd>S</kbd> <kbd>F</kbd>. <kbd>Esc</kbd> or right-click cancels.</li>
<li><b>Delay:</b> the arrow next to New snip → Delay → 3, 5 or 10 seconds, to open a menu before the picture is taken.</li>
<li>Every snip is <b>copied</b> (paste it with ${K("Ctrl V")} into a chat or email) and <b>saved</b> in <code>Pictures\\Ethical Snips</code>. Both can be switched off in <b>⋯</b>.</li></ul>
<h2>Marking it up</h2><ul>
<li><b>Pen</b> <kbd>P</kbd>, <b>Highlight</b> <kbd>H</kbd>, <b>Arrow</b> <kbd>A</kbd>, <b>Box</b> <kbd>R</kbd> (hold <kbd>Shift</kbd> for a square), <b>Text</b> <kbd>T</kbd> (click, then type).</li>

<li><b>Crop</b> <kbd>C</kbd>: drag around the part to keep.</li>
<li>Pick a colour and a size (Thin / Medium / Thick) in the toolbar. <b>Select</b> <kbd>V</kbd> lets you move marks or delete them (<kbd>Delete</kbd>).</li>

<h2>Copy, save, share</h2><ul>
<li><b>Copy</b> (${K("Ctrl C")}) copies the marked-up picture. <b>Save</b> (${K("Ctrl S")}) updates the saved snip; <b>Save as…</b> chooses a name and PNG, JPG, WebP or BMP.</li>
<li><b>Open in Photo Editor</b> for bigger edits (layers, filters, text effects).</li>
<li>Snip also marks up any picture: <b>⋯ → Open a picture</b> (${K("Ctrl O")}), paste one (${K("Ctrl V")}) or drop a file on the window.</li></ul>
<h2>Settings (⋯ menu)</h2><p>Copy every snip · Save every snip automatically · Keep running in the tray for ${K("Ctrl PrtScn")} ·

It needs ${K("Ctrl")}, ${K("Alt")} or the Windows key (F-keys work alone). Avoid shortcuts other programs use, like ${K("Ctrl Shift S")} (Save As). The status bar shows the shortcut in use, or tells you if another program already has it.</p>
<h2>With AI</h2><p>If you connected Snip to Claude, you can ask “take a screenshot of the Excel window and save it to my Desktop”. Claude only takes
screenshots when you ask, and the pictures are saved on your PC.</p>

@@ troubleshooting
title: Troubleshooting & FAQ
keywords: problem error not working won't start crash missing right click font ffmpeg antivirus slow doc xls ppt
---
<h3>An app won't start</h3>
<p>Run the installer from <a href="https://ethicalapp.org">ethicalapp.org</a> again — it repairs the installation and keeps your settings, notes and reminders.</p>
<h3>“Windows protected your PC” when installing</h3><p>Click <b>More info → Run anyway</b>. Windows shows this for new programs it doesn't know yet. Check the download's SHA-256 fingerprint on the website if you want to be sure it's genuine.</p>
<h3>The right-click entries are missing</h3><p>Run the installer again and tick the right-click option. On Windows 11 look under <b>Show more options</b>.</p>
<h3>“Unsupported file type” / old Office files</h3><p>.doc, .xls and .ppt aren't supported — save them as .docx/.xlsx/.pptx first. .rar archives can't be extracted.</p>
<h3>Text looks different from the original</h3><p>The fonts come from your PC. If a document uses a font you don't have, a look-alike is used. Install the font and reopen.</p>
<h3>Something is missing after saving an Excel/PowerPoint file</h3><p>See <a href="#compat">File compatibility</a> — the app warns about features it can't keep. Keep the original and use Save As.</p>
<h3>A video conversion failed</h3><p>The error message comes from FFmpeg. Common causes: the file is damaged or still downloading, it has no sound (for audio formats) or no picture (for video formats). Try MP4 (H.264) first — it works with almost everything.</p>
<h3>Antivirus warning</h3><p>Some antivirus programs are suspicious of new programs they haven't seen before. EthicalApp's full source code is public on <a href="https://github.com/CBGGitHub/ethicalapp">GitHub</a>, and the website shows each download's fingerprint.</p>
<h3>The apps are in the wrong language</h3><p>Click <b>🌐</b> at the bottom of the EthicalApp window — see <a href="#language">Changing the language</a>.</p>
<h3>It feels slow</h3><p>Huge spreadsheets (100k+ formulas), very large photos with many layers, and long 4K videos take longer. The converter shows progress for each file.</p>

@@ glossary
title: Glossary
keywords: glossary terms meaning definition bitrate crf codec lossless lossy dpi layer blend placeholder master
---
<table>
<tr><td><b>Bitrate</b></td><td>How much data per second audio/video uses (e.g. 192k). Higher = better quality, bigger file.</td></tr>
<tr><td><b>Blend mode</b></td><td>How a layer mixes with the layers below it (Multiply, Screen…).</td></tr>
<tr><td><b>Codec</b></td><td>The method used to compress audio/video (H.264, H.265, AAC, MP3…).</td></tr>
<tr><td><b>CRF</b></td><td>Video quality setting: lower = better quality, bigger file.</td></tr>
<tr><td><b>DPI</b></td><td>Dots per inch — resolution when printing or turning PDFs into pictures.</td></tr>
<tr><td><b>Feather</b></td><td>A soft, gradual edge on a selection.</td></tr>
<tr><td><b>Flatten</b></td><td>Merge all layers into one picture.</td></tr>
<tr><td><b>Layer</b></td><td>One sheet in a stack of transparent sheets that make up a picture.</td></tr>
<tr><td><b>Lossless</b></td><td>Compression with no quality loss (PNG, FLAC, ZIP). <b>Lossy</b> throws away detail to save space (JPG, MP3, MP4).</td></tr>
<tr><td><b>Master / layout</b></td><td>In PowerPoint files, the hidden design slides that give real slides their background, fonts and logo.</td></tr>
<tr><td><b>Named range</b></td><td>A name (like <code>Prices</code>) that stands for cells in a spreadsheet.</td></tr>
<tr><td><b>Placeholder</b></td><td>An empty “Click to add …” box on a slide.</td></tr>
<tr><td><b>Redact</b></td><td>Permanently remove content from a PDF.</td></tr>
<tr><td><b>Tolerance</b></td><td>How different a colour may be and still count as “similar” (magic wand, paint bucket).</td></tr></table>
