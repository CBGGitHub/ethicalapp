@@ setup
title: アプリのインストールと起動
keywords: インストール インストーラー ダウンロード 更新 アンインストール スタート メニュー 初めて
---
<h2>インストール</h2>
<ol><li><a href="https://ethicalapp.org">ethicalapp.org</a> からインストーラーをダウンロードして実行します。管理者パスワードは不要です。</li>
<li>Windows に「Windows によって PC が保護されました」と表示されたら、<b>詳細情報 → 実行</b> をクリックします。これはまだあまり知られていない新しいプログラムで表示されるものです。ダウンロードが本物かどうかは、Web サイトに載っている SHA-256 フィンガープリントで確認できます。</li>
<li><b>すべて</b>、<b>オフィス アプリのみ</b> を選ぶか、必要なアプリだけにチェックを入れます。</li>
<li>オプション: デスクトップ ショートカット、右クリック メニューの「Ethical … で開く」、Sticky Notes / Snip / Planner を Windows と一緒に起動、<b>選んだアプリを Claude に接続</b>（<a href="#ai-claude">AI でアプリを使う</a> を参照）。</li>
<li><b>EthicalApp をタスクバー / スタートにピン留めするのを手伝う</b>: Windows ではプログラムが自分自身をピン留めできないため、ランチャーが必要な 2 回のクリックを案内します（タスクバーのアイコンを右クリック → <b>タスク バーにピン留めする</b>、またはスタートで <b>EthicalApp</b> を右クリック → <b>スタートにピン留めする</b>）。ランチャーの <b>タスクバーまたはスタートにピン留め…</b> リンクからいつでも再表示できます。</li></ol>
<h2>起動</h2>
<p><b>EthicalApp</b>（スタート メニューまたはデスクトップ）を開くと、インストールしたすべてのアプリが 1 つのウィンドウに並びます。タイルをクリックするか、<b>ファイルを開く…</b>（<kbd>Ctrl</kbd>+<kbd>O</kbd>）を使うか、ファイルをドロップすると、それぞれ適切なアプリで開きます。各アプリは <b>スタート → EthicalApp</b> にもあります。</p>
<h2>更新とアンインストール</h2>
<p>更新するには、新しいインストーラーを実行します。古いバージョンを置き換え、設定・メモ・リマインダーはそのまま残ります。すべて削除するには <b>設定 → アプリ → EthicalApp → アンインストール</b>（再インストールに備えて、メモとリマインダーは PC に残ります）。</p>
<h2>ソース コードから（開発者向け）</h2>
<p>ソース コードはすべて公開されています — <a href="#sharing">ソース コードと自分でビルドする方法</a> を参照してください。</p>

@@ language
title: 言語の変更
keywords: 言語 翻訳 日本語 英語 language
---
<p>EthicalApp は English、Español、Português (Brasil)、Français、Deutsch、Italiano、Nederlands、Polski、Türkçe、Русский、Bahasa Indonesia、日本語、한국어、简体中文 で使えます。</p>
<ol><li><b>EthicalApp</b> ウィンドウを開きます（スタート メニュー）。</li>
<li>下にある <b>🌐</b> をクリックして言語を選びます。<b>Windows と同じ</b> は Windows の表示言語に従います — これが既定です。</li>
<li>EthicalApp の再起動を承認します。すでに開いているアプリは、次に起動したときに切り替わります。</li></ol>
<p>選んだ言語は、すべての Ethical アプリ、このガイド、ダイアログ（開く/保存、色）に適用されます。日付もその言語で表示されます。</p>
<div class="tip">ファイルの内容は変わりません。文書は書いた言語のままです。翻訳されるのはボタンとメニューだけです。</div>

<p>インストーラーで右クリックのオプションにチェックを入れると、Windows の右クリック メニューに次の項目が追加されます（自分のアカウントのみ — 管理者権限は不要です）:</p>
<table><tr><th>右クリックするもの</th><th>表示される項目</th></tr>
<tr><td>.pdf</td><td>Ethical PDF Editor で開く</td></tr>
<tr><td>.docx</td><td>Ethical Document Editor で開く</td></tr>
<tr><td>.xlsx, .csv</td><td>Ethical Spreadsheet Editor で開く</td></tr>
<tr><td>.pptx</td><td>Ethical Presentation Editor で開く</td></tr>
<tr><td>.psd .png .jpg .webp .bmp .gif .tif .ora</td><td>Ethical Photo Editor で開く</td></tr>

<p>インストーラーをもう一度実行して右クリックのオプションのチェックを外すか、EthicalApp をアンインストールすると、項目も一緒に消えます。</p>

---
<p>EthicalApp はオープンソース（AGPL-3.0）です。ソース コードはすべて GitHub にあります: <a href="https://github.com/CBGGitHub/ethicalapp">github.com/CBGGitHub/ethicalapp</a>。各インストーラーのソース コードの ZIP も <a href="https://ethicalapp.org">ethicalapp.org</a> にあります。</p>
<h2>友だちに教える</h2>
<p><a href="https://ethicalapp.org">ethicalapp.org</a> のリンクを送ってください — 常に最新で安全なバージョンです。</p>
<h2>ソースからインストーラーをビルドする</h2>
<ol><li><b>Python 3.14</b> と <b>Inno Setup 6</b> をインストールします。</li>
<li>ソース フォルダーで <code>python -m venv .venv</code> を実行し、続けて <code>.venv\\Scripts\\python -m pip install -r requirements.txt</code> を実行します。</li>
<li>アプリを直接起動する（例: <code>.venv\\Scripts\\python apps\\suite_launcher.py</code>）か、<code>.venv\\Scripts\\python installer\\build.py</code> でインストーラーをビルドします。</li></ol>

@@ pdf-basics
title: PDF: 開く・表示・テキスト検索
keywords: ズーム サムネイル ページ パネル 検索 探す パスワード
---
<p>PDF は <b>ファイル → 開く</b>（<kbd>Ctrl</kbd>+<kbd>O</kbd>）、ウィンドウへのドラッグ、または右クリック → <i>Ethical PDF Editor で開く</i> で開きます。パスワード付きの PDF はパスワードを尋ねます。</p>
<h2>移動</h2><ul>
<li><b>ズーム:</b> <kbd>Ctrl</kbd>+マウス ホイール、ズーム ボックス、<i>幅に合わせる</i>（<kbd>Ctrl</kbd>+<kbd>1</kbd>）、実際のサイズ（<kbd>Ctrl</kbd>+<kbd>0</kbd>）。</li>
<li><b>ページ パネル</b>（左）: サムネイルをクリックするとそのページへ移動します。ページ操作には <kbd>Ctrl</kbd>/<kbd>Shift</kbd> で複数選択します。右クリックでページ メニュー。</li>
<li><b>ページへ移動:</b> ページ ボックスに番号を入力します。</li></ul>
<h2>テキストの検索</h2><p><b>テキストを検索…</b> に入力して <kbd>Enter</kbd> を押します。<kbd>F3</kbd> / <b>次へ</b> と <b>前へ</b> で結果を移動します（すべて強調表示、現在の結果はオレンジ）。</p>
<h2>テキストのコピー</h2><p><b>選択</b> ツールでテキストをドラッグし、<kbd>Ctrl</kbd>+<kbd>C</kbd> を押します。</p>

@@ pdf-edit-text
title: PDF: 既存テキストの編集とテキストの追加
keywords: テキスト編集 文字を変える フォント 誤字 テキスト追加
---
<h2>PDF にもともとあるテキストを変更する</h2><ol>
<li><b>テキストを編集</b> ツールを選びます。</li><li>変更したい行をクリックします。</li>
<li>ダイアログに行のテキスト、フォント、サイズ、太字/斜体、色が表示されます — 必要な部分を変えて OK をクリックします。</li></ol>
<p>アプリは PDF のフォントを認識し、PC にインストールされている対応フォント（例: Calibri、Times New Roman）を選びます。インストールされていない場合は似たフォントを使います。</p>
<div class="warn">編集は 1 行ずつです。回転したテキストや縦書きのテキストは編集できません。</div>
<h2>新しいテキストを追加する</h2><p><b>テキストを追加</b> を選び、置きたい場所をクリックして入力し、インストール済みの好きなフォントを選びます。本物のページ テキストになるので、あとから <b>テキストを編集</b> で変更できます。</p>

@@ pdf-forms-sign
title: PDF: フォームの入力と署名
keywords: フォーム フィールド チェック ボックス 入力 署名 サイン 描く
---
<h2>フォーム</h2><p>フォームのフィールドは薄い青で表示されます（<i>表示 → フォーム フィールドを強調表示</i> でオフにできます）。<b>選択</b> ツールでフィールドをクリックします。テキスト フィールドは文字を尋ね、チェック ボックスはオン/オフが切り替わり、ドロップダウンは選択肢を表示します。</p>

<li>ページをクリックして配置します。もう一度クリックすると複製を置けます。あとで <b>選択</b> で移動できます。</li></ol>

<h2>並べ替え</h2><p><b>昇順 A→Z / 降順 Z→A</b> は現在の列でデータを並べ替えます（見出しは自動で認識）。<i>データ → 並べ替え…</i> では最大 3 列まで指定できます。空のセルは常に最後になります。</p>
<h2>フィル</h2><ul><li><kbd>Ctrl</kbd>+<kbd>D</kbd> 下方向へコピー / <kbd>Ctrl</kbd>+<kbd>R</kbd> 右方向へコピー — 最初のセルをコピーします（数式は調整されます）。</li>
<li><i>編集 → 連続データの作成</i>: 最初のセルに 1 と 2（または 5 と 10、日付）を入力し、範囲を選ぶとパターンが続きます。</li></ul>
<h2>コピーと貼り付け</h2><p>数式は貼り付けると調整されます。<b>値のみ貼り付け</b>（<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>V</kbd>）は数式ではなく結果を貼り付けます。1 つのセルを選択範囲にコピーすると範囲全体が埋まります。ほかのプログラムからコピーした（タブ区切りの）テキストはセルに分割されます。</p>
<h2>その他</h2><ul><li>行や列の挿入 / 削除（メニューまたは右クリック）。</li>
<li><i>データ → 重複の削除</i>。</li><li>検索と置換（<kbd>Ctrl</kbd>+<kbd>F</kbd>）、全シートも対象にできます。</li>
<li>コメント（<kbd>Shift</kbd>+<kbd>F2</kbd>）— 赤い三角で示され、マウスを重ねると読めます。</li></ul>
