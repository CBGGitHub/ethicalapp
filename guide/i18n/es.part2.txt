Los vídeos privados, solo para miembros, con restricción de edad o bloqueados por región no se pueden descargar.</p>

@@ base-basics
title: Base de datos: qué es una base de datos y cómo empezar
keywords: base de datos access sqlite empezar plantilla nueva abrir tabla registro campo panel de navegación guardado automático
---
<p>Una base de datos guarda listas de cosas — contactos, productos, pedidos, tareas — en <b>tablas</b>. Cada fila es un
<b>registro</b> (un cliente), cada columna un <b>campo</b> (su nombre, su correo…). A diferencia de una hoja de cálculo, las tablas se pueden
<a href="#base-relationships">relacionar</a> (un pedido pertenece a un cliente), y puedes hacer preguntas con
<a href="#base-queries">consultas</a> e imprimir <a href="#base-reports">informes</a>.</p>
<h2>Empezar</h2><p>La página de inicio ofrece una <b>Base de datos en blanco</b> o una plantilla lista con datos de ejemplo:
<b>Contactos</b>, <b>Tareas</b>, <b>Inventario</b> (con una consulta de existencias bajas), <b>Clientes y pedidos</b> (tablas relacionadas, una consulta de totales de pedidos y un informe).
También puedes abrir una base de datos o importar Excel/CSV/Access directamente a una nueva.</p>
<h2>La ventana</h2><ul>
<li><b>Izquierda:</b> el panel de navegación — Tablas, Consultas, Informes. Doble clic para abrir; clic derecho para vista Diseño, vista Formulario, Cambiar nombre, Eliminar, Exportar, Nuevo informe.</li>
<li><b>Derecha:</b> pestañas para todo lo que abres.</li></ul>
<div class="tip">No hay botón Guardar para los datos — <b>cada cambio se guarda al momento</b>, como en Access. Usa <i>Archivo → Guardar una copia como</i> para hacer copias de seguridad.</div>
<p>Una base de datos es un solo archivo <b>.db</b> (el formato estándar SQLite, que muchas otras herramientas también abren).</p>

@@ base-tables
title: Base de datos: diseñar tablas y tipos de campo
keywords: vista diseño tabla campo tipo autonumeración texto número moneda fecha sí no obligatorio único predeterminado cambiar nombre
---
<p><b>Crear → Tabla</b> (o clic derecho en una tabla → <b>Vista Diseño</b> para cambiarla). Cada fila del diseñador es un campo:</p>
<table><tr><th>Tipo</th><th>Para</th></tr>
<tr><td>Autonumeración</td><td>un ID que se numera solo (1, 2, 3…) — cada tabla debería tener uno</td></tr>
<tr><td>Texto corto / Texto largo</td><td>nombres, códigos / notas, descripciones</td></tr>
<tr><td>Número entero / Número decimal</td><td>cantidades / medidas</td></tr>
<tr><td>Moneda</td><td>dinero (se muestra como $1,234.50)</td></tr>
<tr><td>Fecha / Fecha y hora</td><td>escribe 2026-10-11, 10/11/2026 o <code>today</code></td></tr>

@@ base-data
title: Base de datos: introducir y buscar datos (hoja de datos y formulario)
keywords: hoja de datos vista formulario nuevo registro eliminar buscar filtrar ordenar editar búsqueda
---
<h2>Vista Hoja de datos</h2><p>Se abre como una hoja de cálculo. Haz clic en una celda y escribe; pulsa <kbd>Intro</kbd> para guardarla.</p><ul>
<li><b>Nuevo registro:</b> escribe en la última fila marcada con <b>✱</b>, o pulsa <b>＋ Nuevo registro</b>.</li>
<li><b>Eliminar:</b> selecciona registros → <b>✖ Eliminar</b>.</li>
<li><b>Ordenar:</b> haz clic en el encabezado de una columna (otra vez para invertir).</li>
<li>El cuadro <b>Buscar en todos los campos</b> filtra mientras escribes. <b>Filtrar por selección</b> muestra solo los registros con el valor de la celda actual; <b>Quitar filtro</b> vuelve a mostrarlo todo.</li>
<li>Los campos Sí/No son casillas. Los campos relacionados con otra tabla (p. ej. el cliente de un pedido) muestran una <b>lista desplegable de nombres</b> en lugar de números de ID.</li></ul>
<h2>Vista Formulario</h2><p>Un registro cada vez, con un cuadro por campo — más cómodo para escribir registros largos.

<p>Si algo no se puede guardar, recibes una explicación clara — p. ej. un campo obligatorio está vacío, un valor único ya se usa o un registro relacionado no existe.</p>

@@ base-queries
title: Base de datos: consultas (hacer preguntas a tus datos)
keywords: consulta diseño criterios ordenar totales suma contar agrupar sql vista unir relacionada
---
<p><b>Crear → Consulta</b>. Una consulta elige campos, filtra registros y los ordena — p. ej. “todos los pedidos enviados este mes, los más recientes primero”. Las consultas guardadas aparecen en <b>Consultas</b> y siempre muestran los datos actuales.</p>
<h2>Pestaña Diseño</h2><ol>
<li>Elige la <b>tabla principal</b>. Marca las <b>tablas relacionadas</b> para usar también sus campos (necesita una <a href="#base-relationships">relación</a>).</li>
<li><b>＋ Añadir campo</b> (o <b>Añadir todos los campos</b>), y para cada uno: <b>Mostrar</b>, <b>Ordenar</b> y <b>Criterios</b>.</li>
<li><b>▶ Ejecutar</b> para ver los resultados; <b>💾 Guardar consulta…</b> para conservarla.</li></ol>
<h2>Ejemplos de criterios</h2><table>
<tr><td><code>&gt;100</code>, <code>&lt;=50</code>, <code>&lt;&gt;0</code></td><td>comparaciones</td></tr>
<tr><td><code>"London"</code> o <code>London</code></td><td>exactamente esto</td></tr>
<tr><td><code>"London" Or "Paris"</code></td><td>uno u otro</td></tr>
<tr><td><code>Like "A*"</code></td><td>empieza por A (<code>*</code> = lo que sea, <code>?</code> = un carácter)</td></tr>
<tr><td><code>Between 1 And 50</code></td><td>un rango</td></tr>
<tr><td><code>&gt;=#2026-01-01#</code></td><td>fechas (entre signos #)</td></tr>
<tr><td><code>Is Null</code> / <code>Is Not Null</code></td><td>vacío / no vacío</td></tr>
<tr><td><code>Yes</code> / <code>No</code></td><td>campos Sí/No</td></tr></table>
<h2>Totales</h2><p>Marca <b>Totales</b> para agrupar y sumar — p. ej. Agrupar por cliente, Suma de la cantidad. Los criterios sobre una Suma/Recuento se aplican a los totales.</p>
<h2>Pestaña SQL</h2><p>Muestra la consulta como SQL (el lenguaje estándar de las bases de datos) — puedes editarla directamente. <i>Base de datos → Consola SQL</i> te deja ejecutar cualquier SQL; los comandos que cambian datos preguntan antes.</p>

@@ base-relationships
title: Base de datos: relaciones (relacionar tablas)
keywords: relación vínculo clave externa uno a varios padre hijo eliminación en cascada diagrama
---
<p>Una relación dice “cada registro <b>hijo</b> pertenece a un registro <b>padre</b>” — cada pedido pertenece a un cliente, cada producto a una categoría.</p>
<ol><li>Dale a la tabla hija un campo <b>Número entero</b> que guardará el ID del padre (p. ej. <i>Customer ID</i> en Pedidos).</li>
<li><b>Base de datos → Relaciones</b>: elige la tabla padre y su ID, la tabla hija y su campo “que apunta”, y <b>＋ Añadir relación</b>.</li></ol>
<p>Lo que obtienes:</p><ul>
<li>El campo hijo muestra una <b>lista desplegable de nombres del padre</b> en las hojas de datos y formularios.</li>
<li>Los registros no pueden apuntar a un padre que no existe, y un padre con hijos no se puede borrar por accidente…</li>
<li>…salvo que marques <b>eliminación en cascada</b>: entonces al borrar un padre también se borran sus hijos (p. ej. al borrar un pedido se borran sus líneas).</li>
<li>Las consultas pueden combinar campos de tablas relacionadas.</li></ul>
<p>La ventana muestra un diagrama de todas las tablas con líneas entre los campos relacionados (1 ── ∞).</p>

title: Base de datos: informes e impresión

---
<p><b>Crear → Informe</b> (o clic derecho en una tabla/consulta → Nuevo informe). Elige:</p><ul>
<li>los <b>datos</b> (cualquier tabla o consulta) y un <b>título</b>;</li>
<li>qué <b>campos</b> mostrar (márcalos y arrastra para cambiar el orden);</li>
<li><b>Agrupar por</b> un campo (p. ej. una sección por cliente) y <b>Ordenar por</b>;</li>

@@ planner
title: Planner: recordatorios y un calendario
keywords: agenda recordatorio recordatorios calendario evento alarma suplementos pastillas medicina diario repetir notificación posponer cumpleaños cita
---
<p><b>Ethical Planner</b> te recuerda las cosas a tiempo — “tomar los suplementos todos los días a las 8:00”, “dentista mañana a las 14:30”,
“cumpleaños de mamá” — con una tarjeta que aparece en una esquina de la pantalla.</p>
<h2>Recordatorios y eventos</h2><ul>
<li><b>⏰ Nuevo recordatorio</b> (${K("Ctrl N")}) es para cosas que <i>haces</i>: la ventana tiene un botón <b>Hecho</b> y puedes marcarlo en la lista.</li>
<li><b>📅 Nuevo evento</b> (${K("Ctrl E")}) es para cosas que <i>pasan</i>: citas, cumpleaños. Recibes un aviso antes (15 minutos por defecto).</li>
<li>Los botones de <b>Inicio rápido</b> rellenan los más habituales: suplementos diarios, beber agua, noche de sacar la basura, un cumpleaños.</li>

y “cada N” (cada 2 días, cada 3 semanas…). <b>Dejar de repetir después de</b> pone una fecha final. Un recordatorio mensual del día 31 ocurre el último día de los meses más cortos.</p>
<h2>Avisos y la ventana emergente</h2><ul>
<li>Elige <b>Aviso</b> (a la hora, 5/10/15/30 minutos, 1–2 horas, 1–2 días o una semana antes) y, si quieres, un segundo (<b>También</b>), p. ej. un día antes <i>y</i> una hora antes.</li>

<li>La tarjeta se queda hasta que haces clic en <b>Hecho</b>/<b>Aceptar</b>, <b>Posponer</b> (5 minutos … mañana por la mañana) o ✕. Se muestra aunque esté activado el Asistente de concentración de Windows.</li>
<li>¿El PC estaba apagado o en reposo? Lo que te perdiste en las últimas 12 horas aparece la próxima vez, marcado como <i>no realizado</i>.</li>
<li>Cada aviso suena con un timbre suave (el sonido propio de Planner, así que funciona aunque los sonidos de notificación de Windows estén silenciados). Pruébalo: <b>⋯ → Probar una ventana de recordatorio</b>. Activa o desactiva el sonido en <b>⋯</b>.</li>
<li><b>Reloj:</b> las horas siguen el reloj de tu PC. Elige <b>⋯ → Reloj → 12 horas (8:00 PM)</b> o <b>24 horas (20:00)</b> – por defecto Planner usa lo mismo que Windows.</li></ul>
<h2>La lista</h2><ul>
<li>Muestra el día seleccionado y los 6 días siguientes. Haz clic en una fecha del calendario para mirar más adelante; <b>Hoy</b> (${K("Ctrl T")}) vuelve.</li>
<li>Marca la casilla para dar un recordatorio por hecho ese día (se tacha). Los atrasados salen en rojo.</li>
<li>Clic derecho en un elemento: Editar, Marcar como hecho / Sin hacer, <b>Omitir solo este</b> (para un elemento que se repite), Eliminar.</li>
<li>Los días en negrita del calendario tienen eventos o recordatorios menos frecuentes. <b>Lo próximo</b> muestra el siguiente aviso.</li></ul>
<h2>Mantenerlo en marcha</h2><p>Los recordatorios solo pueden aparecer mientras Planner está en marcha, así que cerrar la ventana lo deja en la bandeja (abajo a la derecha de la barra de tareas).
La primera vez te pregunta si quieres <b>iniciarlo con Windows</b> — di que sí (o márcalo en el instalador o en <b>⋯</b>). <b>Salir de Ethical Planner</b> en el menú de la bandeja lo detiene.</p>
<h2>Dónde se guarda</h2><p><code>%APPDATA%\\Ethical Suite\\Planner\\planner.json</code> (más una copia de seguridad). Nunca se sube a ningún sitio; al desinstalar se conserva.</p>
<h2>Con IA</h2><p>Si conectaste Planner a Claude: “recuérdame tomar las vitaminas todos los días a las 8”, “¿qué tengo esta semana?”,
“ya me tomé las pastillas” (lo marca como hecho), “pasa el dentista al jueves a las 3”.</p>

@@ troubleshooting
title: Solución de problemas y preguntas frecuentes
keywords: problema error no funciona no arranca bloqueo falta clic derecho fuente ffmpeg antivirus lento doc xls ppt idioma
---
<h3>Una aplicación no arranca</h3>
<p>Vuelve a ejecutar el instalador de <a href="https://ethicalapp.org">ethicalapp.org</a> — repara la instalación y conserva tus ajustes, notas y recordatorios.</p>
<h3>“Windows protegió su PC” al instalar</h3><p>Haz clic en <b>Más información → Ejecutar de todas formas</b>. Windows muestra esto con programas nuevos que todavía no conoce. Comprueba la huella SHA-256 de la descarga en la web si quieres estar seguro de que es auténtica.</p>
<h3>Faltan las entradas del clic derecho</h3><p>Vuelve a ejecutar el instalador y marca la opción del clic derecho. En Windows 11 mira en <b>Mostrar más opciones</b>.</p>
<h3>“Tipo de archivo no compatible” / archivos antiguos de Office</h3><p>.doc, .xls y .ppt no son compatibles — guárdalos primero como .docx/.xlsx/.pptx. Los archivos .rar no se pueden extraer.</p>
<h3>El texto se ve distinto del original</h3><p>Las fuentes vienen de tu PC. Si un documento usa una fuente que no tienes, se usa una parecida. Instala la fuente y vuelve a abrirlo.</p>
<h3>Falta algo después de guardar un archivo de Excel/PowerPoint</h3><p>Mira <a href="#compat">Compatibilidad de archivos</a> — la aplicación avisa de lo que no puede conservar. Conserva el original y usa Guardar como.</p>
<h3>Ha fallado una conversión de vídeo</h3><p>El mensaje de error viene de FFmpeg. Causas habituales: el archivo está dañado o todavía se está descargando, no tiene sonido (para formatos de audio) o no tiene imagen (para formatos de vídeo). Prueba primero MP4 (H.264) — funciona con casi todo.</p>
<h3>Aviso del antivirus</h3><p>Algunos antivirus desconfían de los programas nuevos que no han visto antes. Todo el código fuente de EthicalApp es público en <a href="https://github.com/CBGGitHub/ethicalapp">GitHub</a>, y la web muestra la huella de cada descarga.</p>
<h3>Las aplicaciones están en el idioma equivocado</h3><p>Haz clic en <b>🌐</b> abajo en la ventana de EthicalApp — mira <a href="#language">Cambiar el idioma</a>.</p>
<h3>Va lento</h3><p>Las hojas de cálculo enormes (más de 100.000 fórmulas), las fotos muy grandes con muchas capas y los vídeos 4K largos tardan más. El conversor muestra el progreso de cada archivo.</p>
